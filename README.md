# Image to PDF Converter

Convert images to perfectly formatted A4 PDFs with text overlay capabilities.

## Features

- 📁 Image upload (JPEG/PNG)
- ✏️ Text overlay customization
- 📏 Millimeter-precise A4 PDF generation
- 🔄 Real-time preview
- 📱 Responsive design

## Installation

1. Clone repo:
    ```bash
    git clone https://github.com/olaa30-j/Image-Editor.git
    cd image-to-pdf-converter

2. Install dependencies:
    ```bash
    npm install

3. Start dev server:
    ```bash
    npm run dev

## Usage

1. Upload image
2. Set dimensions (mm)
3. Add text overlay
4. Configure layout
5. Generate PDF
